# GEO Score Analyzer v3 — 기사 GEO 점수 측정 + 재구성

> 웹 도구 실행 결과 캡처(PDF, 2026.06.09) 분석 문서
> Google SEO + GEO(Generative Engine Optimization) 특화 100점 척도 · URL 자동 분석 · 기사 재구성 + 복사 기능

## 개요

기사 URL을 입력하면 SEO(검색엔진 최적화)와 GEO(생성형 AI 인용 최적화) 관점에서 100점 만점으로 채점하고, 점수가 낮은 영역을 반영해 제목·메타·첫 문단·본문·JSON-LD까지 자동 재구성해 주는 도구입니다. v3에서 "재구성 생성하기" 기능이 추가되어 분석 → 개선안 → 복사·CMS 반영까지 한 흐름으로 이어집니다.

## 채점 체계 (총 100점)

### SEO 기반 (50점)

| 카테고리 | 항목 | 배점 |
|---|---|---|
| 제목·메타 | 제목 태그 존재 | 5 |
| 제목·메타 | 제목 태그 길이 (45–65자) | 5 |
| 제목·메타 | 메타 디스크립션 존재 | 5 |
| 제목·메타 | 메타 디스크립션 길이 (120–160자) | 3 |
| 헤딩 구조 | H1 태그 (1개) | 5 |
| 헤딩 구조 | H2 태그 (2개 이상) | 5 |
| 이미지 | 이미지 alt 텍스트 | 5 |
| 링크 | 내부 링크 (3개+) | 5 |
| 링크 | 외부 신뢰 링크 | 4 |
| 콘텐츠 | 본문 길이 (800자+) | 4 |
| 콘텐츠 | Canonical 태그 | 4 |

### GEO 특화 (50점)

| 카테고리 | 항목 | 배점 |
|---|---|---|
| 팩트 밀도 | 숫자·퍼센트 밀도 (5개+) | 10 |
| 팩트 밀도 | 날짜·연도 명시 (2개+) | 8 |
| AI 인용 구조 | 첫 문단 완결성 (첫 150~200자에 기업명·수치·핵심 사실) | 10 |
| AI 인용 구조 | JSON-LD 구조화 데이터 | 7 |
| AI 인용 구조 | Article/NewsArticle 스키마 | 8 |
| E-E-A-T | 저자(Byline) 정보 | 4 |
| E-E-A-T | 발행 날짜 태그 | 3 |

등급은 점수에 따라 부여됩니다(예: 73점 = C "보통 — 개선 여지 있음").

## 실행 예시 (더바이오 기사 분석)

- 대상: thebionews.net 기사 "맥킨지 파트너 — 빅파마, 中 지정학적 리스크에 韓 관심"
- 결과: **73/100 (C)** — SEO 기반 46/50, GEO 특화 27/50
- 통과: 제목·메타 존재, H1, alt 텍스트(15개 중 14개), 내부 링크 95개, 본문 5,602자, canonical, 저자·날짜 태그
- 감점: 제목 68자(최적 45–65자), H2 1개, 첫 문단에 숫자 없음, **JSON-LD 없음(0/7), NewsArticle 스키마 없음(0/8)**

전형적 패턴: 언론사 CMS 기사는 SEO 기본기는 갖췄지만, AI 인용을 위한 구조화 데이터(JSON-LD/NewsArticle)가 빠져 GEO 점수를 크게 잃습니다.

## 개선 권고 로직

우선순위(높음/낮음)를 매겨 제시합니다.

- 우선순위 높음: JSON-LD 구조화 데이터 추가, `"@type":"NewsArticle"` 스키마 설정
- 우선순위 낮음: 제목 45–65자 조정, H2 소제목 2개 이상, 첫 150자 내 기업명·수치 배치, 날짜·연도 2회 이상 명시

## 재구성 기능 (v3 신규)

분석 결과를 반영해 영역별 최적화 초안을 생성하고 개별 복사할 수 있습니다.

1. **제목(Title)** — 길이·팩트 포함 여부 점검
2. **메타 디스크립션** — 120–160자 요약 생성
3. **첫 문단(GEO 핵심)** — 100–300자, AI가 인용하기 좋은 팩트 완결 구조
4. **본문** — H2 소제목 구조 제안 (AI는 헤딩 구조 기반으로 내용 파악)
5. **JSON-LD** — NewsArticle 스키마 템플릿 생성(언론사명·로고·대표 이미지만 채워 CMS에 붙여넣기)
6. **기사 전문 복사** — 제목+메타+첫문단+본문 일괄 복사

## 시사점

- GEO는 SEO와 별개 축: 검색 노출이 좋아도 AI 답변 인용에는 팩트 밀도·첫 문단 완결성·구조화 데이터가 결정적입니다.
- 언론사 실무에서 가장 큰 레버리지는 JSON-LD(NewsArticle) 일괄 적용 — 이 사례에서만 15점 회복 여지가 있습니다.
